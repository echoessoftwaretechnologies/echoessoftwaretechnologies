# Echoes Explorer

A professional web browser with a clean, corporate design featuring a white background and #1864ff blue accent theme.

## Features

- Clean, professional interface with white background and blue accents
- Full browser functionality (back, forward, refresh, home)
- Secure connection indicators
- Address bar with search capability
- Responsive design that works on different screen sizes
- Corporate-style window controls

## How to Use

### Option 1: Using Node.js (Recommended)

1. Make sure you have Node.js installed on your system
2. Open a terminal/command prompt in this directory
3. Install dependencies: `npm install`
4. Start the browser: `npm run dev`
5. The browser will open automatically in your default browser

### Option 2: Direct HTML File

1. Simply open `index.html` in any modern web browser
2. Note: Some features may be limited due to browser security restrictions when running locally

## Browser Controls

- **Back/Forward**: Navigate through browsing history
- **Refresh**: Reload the current page
- **Home**: Return to the homepage
- **Address Bar**: Enter URLs or search terms
- **Bookmarks**: Access saved bookmarks (coming soon)
- **Menu**: Access browser settings (coming soon)

## Security Notice

This is a frontend demonstration of a browser interface. For security reasons, this implementation uses an iframe with sandbox attributes to limit potential security risks when browsing external sites.

The Echoes Explorer browser features:
